v0.20.3 fixes seven things a real project ran into while being built with the kit.

## Updating

Type `/maintain` in your project and accept the kit update. Start a new session afterwards so it reads the new skills. Nothing else is needed. A project founded before this release keeps GitHub's squash and rebase merges switched on in its repository settings; the kit no longer uses them either way.

If you are still on v0.19.3 or older, follow the [v0.20.0 update steps](https://github.com/gwpicard/ai-build-kit/releases/tag/v0.20.0) to finish the move to six commands.

## What changes

- When GitHub will not start a project's check at all, for example because the account's billing stops it, the kit no longer calls the check red. It runs the same checks on your computer and tells you once. On a private exploration that is enough to merge. On the other two paths the merge waits until GitHub runs the check. The check is switched off only if you ask, and `/maintain` reminds you while it stays off.
- A merge always keeps every commit of the piece. Founding also turns off GitHub's squash and rebase merges on a new repository.
- A piece's labels are right after it merges: `ready` becomes `building` when the build starts, and both are gone once it closes.
- Founding records which version the masterplan was written against, so later builds can keep that record moving. Where a project has no such record, `/what-now` points you to `/maintain` to make one.
- `/shape` never starts building because you picked one of its answers. A build starts only when you ask for it.
- If you ask for more while a piece is being built, the kit first asks whether it belongs in this piece or a new one. It asks to merge only after you have tried the result.
- A build gives you one address to try it on, stops any older preview first, checks pages in a browser tab of its own rather than yours, and stops its previews when you are done.

## Evidence and limits

Each change has a source check that fails when its rule is removed, and all 93 rehearsals pass. Before release, two throwaway projects were founded and built with Claude Code from a preview. Every change above held there, except two that the run did not reach: a private exploration merging on the local checks alone, and `/what-now` pointing to `/maintain`. Four older faults that run found are written up for the next release.
