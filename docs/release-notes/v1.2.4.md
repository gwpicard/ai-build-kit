**Who gets what.** Apart from the kit's version number, nothing in your project changes. The update carries no change to the commands, the background skills or the checks.

## Updating

Run `/maintain` in an existing project. It names the new version, summarises these notes and asks for your approval before it updates. You do not need to start a new session, because no skill's instructions changed. No other action is required, and the update does not change your tool's data.
