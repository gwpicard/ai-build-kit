After updating, start a new session (or /reload-plugins) and type /maintain again.

The session that runs the update still follows the release it replaces, so it
cannot finish the move to six commands. The next /maintain visit does, on any
day. It offers to remove the old /fix, /queue, /sync and /ship skills. On the
shared installer route that is `npx skills remove fix queue sync ship`, which
the visit runs on your yes. It also offers to rewrite the command list in your
AGENTS.md and to add the newer safety rules, and it changes nothing without
your yes. Until that visit is done, /what-now and /implement say in one line
that the update is not finished.
