v1.1.1 publishes the companion site that v1.1.0 introduced. The kit itself does not change.

## Updating

You do not need to update. A project on v1.1.0 has the same skills, checks and recipes. If `/maintain` offers v1.1.1, accepting it changes only the version the project reports.

## What changes

- The site at https://gwpicard.github.io/ai-build-kit/ now builds on GitHub. The v1.1.0 build stopped at the search index, because the site's lockfile listed the search tool for macOS only. The lockfile now lists it for every system the tool supports.
- Each pull request now builds the site the same way the publish step does, and checks its links, so a site that cannot be built is caught before a release.

## Evidence and limits

All source checks pass, and the site build passes on GitHub in this release's pull request. No replay was run, because no skill changed.
