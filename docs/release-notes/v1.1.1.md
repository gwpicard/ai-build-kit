v1.1.1 makes the companion website from v1.1.0 build and publish on GitHub. The kit itself does not change.

## Updating

You do not need to update. A project on v1.1.0 has the same skills, checks and recipes. If `/maintain` offers v1.1.1, accepting it changes only the version number that the project reports.

## What changes

1. **The site now builds on GitHub.** The site at https://gwpicard.github.io/ai-build-kit/ did not build for v1.1.0. The build stopped at the search index. The site's package lockfile listed the search tool for macOS only. It now includes the packages for every system the tool supports.
2. **A broken site is caught before a release.** Each pull request now builds the site the same way the publish step does, and checks its links.

## What was tested, and what is not proven yet

- All of the kit's own checks pass.
- The site build passes on GitHub in this release's pull request.
- No replay of scripted conversations was run, because no skill changed.
