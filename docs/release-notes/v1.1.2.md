Run `/maintain` to update an existing project. No data migration is required.

The public recipe page is shorter, with overlapping explanations combined
and the remaining testing gaps stated together. Setup, review and deployment
instructions now describe the results the checks actually confirm.

Health checks accept the starter's `database: "reachable"` response and retain
support for the older `database: "ok"` response. The local container check
requires HTTP 200 with the database reachable and HTTP 503 with an invalid
database address. A failed request or container start no longer counts as a
successful 503 test.
