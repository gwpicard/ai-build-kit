AI Build Kit is for people who do not read code. It builds one agreed piece at a time, with machine checks before merge and before going live. It records risks, warns once and respects the owner's choice. Hosting recipes include a backup and a way back. `/maintain` checks the project later. Code, hosting and data stay in the owner's accounts. Replays test the kit's behaviour.

## Choose AI Build Kit if

- You are comfortable with technology but do not write code.
- You want to build and run a small tool for your team in accounts you control.
- You want a recorded risk warning, checks before merge and launch, and a way to maintain the project later.

## Choose another tool if

- You write code and want a developer workflow with test-driven development and code review. Choose [Superpowers](https://github.com/obra/superpowers) or [Addy Osmani's agent skills](https://github.com/addyosmani/agent-skills).
- You want a personal set of engineering skills. Choose [Matt Pocock's skills](https://github.com/mattpocock/skills).
- Your team wants a written specification, plan and task flow. Choose [GitHub Spec Kit](https://github.com/github/spec-kit).
