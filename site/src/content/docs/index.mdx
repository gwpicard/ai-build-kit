![AI Build Kit: build tools you can maintain without reading code](/ai-build-kit/hero.jpg)

AI Build Kit helps people who do not write code build tools with a coding agent, software that reads and changes project files. It suits people who can create accounts and follow technical setup steps.

You describe the tool, and the agent builds one agreed piece at a time. A piece is a small change for one session. By default, you try each change, then decide whether to merge it into the main branch, the project’s main line of development. Each branch is a separate line of work; merging incorporates its changes into another branch.

## Why this kit

You know what your internal tool needs and may discover details as you build. AI Build Kit lets you build and maintain it without reading code.

- **In your accounts.** Each recipe-based tool is a standard Next.js and Supabase project in your GitHub account. It runs on Vercel or a server you rent and manage with Coolify.
- **Recorded process.** Scripts and a second agent check each change. Recipe records show which launch, backup and rollback steps were tried on a live host.

See [how the kit differs](/ai-build-kit/how-it-differs/).

Also read [working with the kit](/ai-build-kit/working-together/), [maintenance](/ai-build-kit/maintaining-your-tool/) and [live data and recovery](/ai-build-kit/live-data/).

## What happens

1. In the founding interview, you describe the tool. A setup script checks Git, Python 3, GitHub sign-in, and access to the repository and its issues.
2. You and the agent agree on a piece; it records the result under "Done when", the criteria you use to judge the work.
3. The agent builds the piece; scripts check it and a reviewer agent assesses the result.
4. By default, you try the change, then tell the agent in conversation to merge the named pull request, a proposal to merge it into the main branch. It records your approval; the merge script checks it and the project check, an automated GitHub run of project tests and kit checks for each pull request.
5. To put the tool live, choose a [hosting recipe](/ai-build-kit/recipes/): a fixed stack and host with steps for preview, launch, backup, restore and rollback. The launch script blocks its live-address record until a backup is confirmed and a way back is defined. It cannot stop a host that deploys on merge.

The checks do not establish that a tool is safe for every purpose. Some work may still need a developer. Read [the design principles](/ai-build-kit/design/) and [what the kit checks](/ai-build-kit/what-it-checks/).
