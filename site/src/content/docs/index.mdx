AI Build Kit helps people who do not write code build tools with a coding agent, an AI tool that can read and change project files. It is for people who are comfortable with technology and want a tool they can keep running in their own accounts.

You explain what the tool should do. The agent helps build it one agreed change at a time. You try each change and decide whether it can go live.

AI Build Kit is designed for people who do not read code. It combines machine checks with a recorded risk warning and hosting steps that include a backup and a way back. [See how it differs from other tools](/ai-build-kit/how-it-differs/).

## What happens

1. You describe the tool you need. The kit checks whether its setup fits.
2. You agree on one task at a time. The kit records what result will count as success.
3. The agent builds the agreed change and runs automatic checks to look for problems.
4. By default, you try the result and say yes before the change joins the main project. Automatic merging is an opt-in. This approval step is called a merge.
5. If you choose hosting, an approved change can then go live for people to use.

The kit does not run a service of its own or store project records. Your code and records stay in accounts you control. Passing checks do not prove that a tool is safe or right for every purpose. A developer may still be needed for some work.

## Principles

- **One agreed piece at a time.** You agree on the result before work starts.
- **The person decides, and the kit explains.** You try the result and decide whether it can merge.
- **A machine holds each rule it can.** Hooks, settings and scripts apply rules every time.
- **Every sentence earns its place.** A machine enforces it, a replay shows it changes the outcome, or it carries a judgement.
- **Small is a reliability feature.** Fewer instructions leave more attention for the rules that matter.
- **Warn once, then respect the decision.** You hear a risk and choose what to do.
- **Build tools the owner can run and share.** The code, hosting and data stay in accounts the owner controls.
- **Test what the kit does.** Checks and replays measure outcomes, not wording.
