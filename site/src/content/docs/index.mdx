AI Build Kit helps people who do not write code build tools with a coding agent, a program that reads and changes project files. It suits people who can create accounts and follow technical setup steps.

You describe the tool. The agent builds one agreed change at a time. You try each change and decide whether it can join the main version of the project.

## What happens

1. You describe the tool. A script checks Git, Python 3 and your GitHub sign-in. The agent checks access to your project repository.
2. You agree on one task. The agent records what result will count as success.
3. The agent builds the task. Scripts check the change, and a reviewer agent checks the result.
4. You try the change and approve it by name. A merge script checks the approval and project checks before it merges.
5. If you host the tool on a supported recipe, a launch script checks the backup and rollback steps.

The checks give evidence. They do not prove that a tool is safe for every purpose. Some work may need a developer. Read [the design principles](/ai-build-kit/design/) and [what the kit checks](/ai-build-kit/what-it-checks/).
