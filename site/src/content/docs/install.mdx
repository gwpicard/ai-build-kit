Open the folder where the tool will live, choose the coding agent you already use, and copy its command. A terminal is an app where you type commands for your computer.

import { Tabs, TabItem } from '@astrojs/starlight/components';

<Tabs>
  <TabItem label="Claude Code">
    In a terminal opened in your project folder, run `claude plugin marketplace add gwpicard/ai-build-kit`, then `claude plugin install ai-build-kit@ai-build-kit --scope local`. Start Claude Code and run `/ai-build-kit:setup-ai-build-kit`.
  </TabItem>
  <TabItem label="Codex">
    In a terminal opened in your project folder, run `npx skills add gwpicard/ai-build-kit` and select Codex. Then ask Codex to run `setup-ai-build-kit`.
  </TabItem>
  <TabItem label="Cursor">
    In a terminal opened in your project folder, run `npx skills add gwpicard/ai-build-kit`, select Cursor and install all the kit's skills. Then ask your agent to run `setup-ai-build-kit`.
  </TabItem>
  <TabItem label="Gemini CLI">
    In a terminal opened in your project folder, run `npx skills add gwpicard/ai-build-kit`, select Gemini CLI and install all the kit's skills. Then ask your agent to run `setup-ai-build-kit`.
  </TabItem>
  <TabItem label="GitHub Copilot">
    In a terminal opened in your project folder, run `npx skills add gwpicard/ai-build-kit`, select GitHub Copilot and install all the kit's skills. Then ask your agent to run `setup-ai-build-kit`.
  </TabItem>
  <TabItem label="Other agents">
    In a terminal opened in your project folder, run `npx skills add gwpicard/ai-build-kit`, select your agent and install all the kit's skills. Then ask your agent to run `setup-ai-build-kit`.
  </TabItem>
</Tabs>

## If setup needs this

The [full installation routes](https://github.com/gwpicard/ai-build-kit/blob/stable/docs/COMPATIBILITY.md#choose-one-installation-route) explain manual setup and the Claude Code plugin.

On a Mac, Codex may need the session launcher from your project folder: `python3 .agents/skills/setup-ai-build-kit/scripts/codex-with-github.py`. The [Codex setup notes](https://github.com/gwpicard/ai-build-kit/blob/stable/.agents/skills/setup-ai-build-kit/references/codex-github.md) explain when to use it.
