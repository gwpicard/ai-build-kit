Make an empty folder for your tool. Open a terminal in that folder. A terminal is an app where you type commands for your computer. Choose your coding agent below and run its commands.

## Before you start

You need Git, Python 3 and the GitHub CLI (`gh`) signed in. If you use an `npx` installation route, you also need Node.js. The setup script checks Git, Python 3 and your GitHub sign-in. It then checks access to the project repository and its issues.

You use six commands: `/setup-ai-build-kit`, `/shape`, `/implement`, `/setup-hosting`, `/maintain` and `/what-now`. Read [supported agents](/ai-build-kit/agents/) to see how much the kit has been tried on each agent.

## If installation fails

The [full installation routes](https://github.com/gwpicard/ai-build-kit/blob/stable/docs/COMPATIBILITY.md#choose-one-installation-route) explain manual setup and the Claude Code plugin.

If Codex on a Mac reports `unable to get password from user`, run this command in your project folder and start Codex from it: `python3 .agents/skills/setup-ai-build-kit/scripts/codex-with-github.py`. The [Codex setup notes](https://github.com/gwpicard/ai-build-kit/blob/stable/.agents/skills/setup-ai-build-kit/references/codex-github.md) explain when to use it.
