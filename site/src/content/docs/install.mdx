Create an empty folder for your tool and open a terminal in it. A terminal lets you run commands on your computer. Choose your coding agent below and follow its installation steps.

## Before you start

You need Git, Python 3 and the GitHub CLI (`gh`), the command-line tool for GitHub. Sign in to `gh` before setup. Installation routes that use `npx` also require Node.js. The setup script checks Git, Python 3 and your GitHub sign-in, then checks access to the project repository and its issues, which hold the work list.

The kit has six commands: `/setup-ai-build-kit`, `/shape`, `/implement`, `/setup-hosting`, `/maintain` and `/what-now`. See [supported agents](/ai-build-kit/agents/) for the evidence behind each agent’s support grade.

## If installation fails

The [full installation routes](https://github.com/gwpicard/ai-build-kit/blob/stable/docs/COMPATIBILITY.md#choose-one-installation-route) explain manual setup and the Claude Code plugin.

If Codex on a Mac reports `unable to get password from user`, run `python3 .agents/skills/setup-ai-build-kit/scripts/codex-with-github.py` in your project folder to start a new Codex session with GitHub access. The [Codex setup notes](https://github.com/gwpicard/ai-build-kit/blob/stable/.agents/skills/setup-ai-build-kit/references/codex-github.md) explain when to use this launcher.
