# Build and run it

Run the `evidence-run` skill and the `second-opinion` skill using the
independent method in AGENTS.md. Decide whether the tool records each request
with a run id, time, level and step, using disposable input. Treat records of
personal data or secrets as a repair. Decide whether the fit check names an
alert recipient. Pass `--request-record yes|no` and `--alerts named|none`.
These are not sensitive areas, and the kit sets up no hosted service for them.
