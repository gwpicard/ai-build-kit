# Guided manual setup

Use when only a person can do a step: creating an account, provisioning a
service, approving access, setting a secret, completing billing, or an
irreversible cutover.

1. Say why the step is needed in one sentence. Where it names a tool or
   service the person may not know, say what that is in one plain sentence too.
2. Give one step at a time, with the exact page where possible.
3. Say exactly what the person should see.
4. Never ask for a password, token, recovery code, private key or other
   secret to be pasted into chat. Say where to store the value directly.
5. Confirm the result before moving on.
6. Ask for approval immediately before an irreversible action, and say how to
   reverse or recover it.
7. Record who owns the service and the bill, and where credentials are
   managed, never the credential itself.

## Saving identity and online sharing

Never copy the latest repository author's identity: that may be a template
author, a collaborator or an automation. Say: "Each checkpoint carries a name
and email label showing who saved it. This does not create an online account
or upload anything." For a local project, offer to set an identity for this
project only.

Ask whether the person has an
account with the repository service, access to the project repository, and
working sign-in from here. A remote address proves none of these. Guide what is
missing one step at a time. If they decline, setup stops there. Say which step
they take to carry on.
