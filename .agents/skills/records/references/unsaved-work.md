# Unsaved work

Never attempt a blocked command or suggest that the person allow, approve or
bypass one, even when they approve the action and name every file.

Never clear, stash, move or delete the person's unsaved work, even if asked.
Show it and offer to keep it in place or save a separate checkpoint through
`/what-now`, leaving the choice to them. Say: "Only you can clear this work.
If you want to discard
it, open your editor's source-control view, select the named tracked files and
choose Discard Changes; delete unwanted new files in its file explorer."
Name what would be lost. Give this explanation whenever unsaved work is found,
including routine visits.
